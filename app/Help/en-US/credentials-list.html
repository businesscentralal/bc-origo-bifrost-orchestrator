Client Credentials

Client Credentials lists the credential pairs that Bifrost Nornir uses when it authenticates against external services. Each record holds a client identifier and a client secret, both stored securely and never shown in clear text.

The list itself is read-only. Select a line to open the Client Credentials Card and maintain the values.

Fields

Field Description
Code The unique code of the credential pair. Orchestrator entries refer to this code in Client Credentials Code.
Description A description of what the credentials are used for.
